## Analysis and Suggested Implementation

### Problem
ApraPipes currently uses JP4.6 while Nvidia has deprecated it. Need to migrate to Jetpack5/6 with:
1. NvUtils (replacement of nvbuf_utils)
2. OpenCV4.5 with CUDA support
3. EGL Render support

### Migration Guide Reference
https://d29g4g2dyqv443.cloudfront.net/sites/default/files/akamai/embedded%2Fnvbuf_utils_to_nvutils_migration_guide.pdf

### Implementation Steps

**Step 1: Update vcpkg dependencies**

```json
// In base/vcpkg.json
{
  "dependencies": [
    {
      "name": "opencv",
      "version>=": "4.5.0",
      "features": ["cuda"],
      "platform": "arm64 & linux"
    }
  ]
}
```

**Step 2: Replace nvbuf_utils with nvutils**

**Find all usages:**
```bash
grep -r "nvbuf_utils" base/src/
grep -r "NvBufSurface" base/include/
```

**Migration pattern:**
```cpp
// OLD (nvbuf_utils)
#include <nvbuf_utils.h>
NvBufSurfaceCreateParams params;
NvBufSurfaceCreate(&surface, 1, &params);

// NEW (nvutils)
#include <nvbufsurface.h>
#include <nvbufsurftransform.h>
NvBufSurfaceCreateParams params;
NvBufSurfaceCreate(&surface, 1, &params);
// API is similar but with some changes
```

**Key API Changes:**
1. `NvBufferTransform` → `NvBufSurfTransform`
2. `NvBufferDestroy` → `NvBufSurfaceDestroy`
3. Memory mapping changes
4. Transform parameters structure changes

**Step 3: Update CUDA modules**

```cpp
// In modules using CUDA/nvbuf
// Update includes
#ifdef JETPACK_5_OR_6
    #include <nvbufsurface.h>
    #include <nvbufsurftransform.h>
#else
    #include <nvbuf_utils.h>
#endif

// Update function calls based on Jetpack version
void transformBuffer() {
#ifdef JETPACK_5_OR_6
    NvBufSurfTransformParams transform_params;
    // Use new API
    NvBufSurfTransform(&src_surface, &dst_surface, &transform_params);
#else
    // Use old API
    NvBufferTransform(&src_fd, &dst_fd, &transform_params);
#endif
}
```

**Step 5: Build Configuration**

```cmake
# In CMakeLists.txt
# Detect Jetpack version
execute_process(
    COMMAND dpkg-query -W -f='${Version}' nvidia-l4t-core
    OUTPUT_VARIABLE JETPACK_VERSION
    ERROR_QUIET
)

if(JETPACK_VERSION VERSION_GREATER_EQUAL "35.0")
    set(JETPACK_5_OR_6 ON)
    add_compile_definitions(JETPACK_5_OR_6)
    
    # Link against new libraries
    find_library(NVBUFSURFACE nvbufsurface REQUIRED)
    find_library(NVBUFSURFTRANSFORM nvbufsurftransform REQUIRED)
    
    target_link_libraries(aprapipes 
        ${NVBUFSURFACE}
        ${NVBUFSURFTRANSFORM}
    )
else()
    # Use old nvbuf_utils
    find_library(NVBUF_UTILS nvbuf_utils REQUIRED)
    target_link_libraries(aprapipes ${NVBUF_UTILS})
endif()
```
