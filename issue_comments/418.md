## Analysis and Suggested Implementation

### Feature Request
Allow Mp4ReaderSource to override playback FPS for faster or slower processing (non-real-time workflows like batch processing or clip generation).

### Current vs Desired Behavior

**Current:** Mp4ReaderSource plays at the file's native FPS (e.g., 30 FPS).

**Desired:** Allow setting custom playback FPS:
- **Faster**: Read at 60 FPS from a 30 FPS file (speed up processing)
- **Slower**: Read at 15 FPS from a 30 FPS file (slow motion)
- **Maximum**: Read as fast as possible (no delay between frames)

### Implementation Design

**Add FPS Override Property:**

```cpp
// In Mp4ReaderSourceProps.h
class Mp4ReaderSourceProps {
public:
    float playbackFPS = 0.0f;  // 0 = use file's native FPS, > 0 = override FPS
    bool unlimitedSpeed = false;  // true = read as fast as possible
};
```

**Usage:**
```cpp
// Read at 2x speed
Mp4ReaderSourceProps props("input.mp4");
props.playbackFPS = 60.0f;  // File is 30 FPS, read at 60 FPS

// Read as fast as possible
props.unlimitedSpeed = true;
```

### Implementation Steps

**Step 1: Update Props**
```cpp
// In Mp4ReaderSourceProps.h
class Mp4ReaderSourceProps : public ModuleProps {
public:
    Mp4ReaderSourceProps(const std::string& _videoPath)
        : ModuleProps(), videoPath(_videoPath), playbackFPS(0.0f) {}
    
    /**
     * Override playback FPS
     * 0 = use file's native FPS (default)
     * > 0 = override with specified FPS
     * Use std::numeric_limits<float>::max() for maximum speed
     */
    float playbackFPS;
    
    void setPlaybackFPS(float fps) {
        playbackFPS = fps;
    }
    
    void setMaximumSpeed() {
        playbackFPS = std::numeric_limits<float>::max();
    }
};
```

**Step 2: Update Mp4ReaderSource**
```cpp
// In Mp4ReaderSource.cpp
bool Mp4ReaderSource::step() {
    // Read frame
    auto frame = demuxer->getFrame();
    if (!frame) {
        sendEOS();
        return false;
    }
    
    // Calculate frame delay
    float targetFPS = (mProps.playbackFPS > 0) ? mProps.playbackFPS : mNativeFPS;
    
    if (targetFPS < std::numeric_limits<float>::max()) {
        auto frameDuration = std::chrono::microseconds(
            static_cast<long>(1000000.0 / targetFPS)
        );
        
        // Sleep until next frame time
        auto now = std::chrono::high_resolution_clock::now();
        auto nextFrameTime = mLastFrameTime + frameDuration;
        
        if (nextFrameTime > now) {
            std::this_thread::sleep_for(nextFrameTime - now);
        }
        
        mLastFrameTime = std::chrono::high_resolution_clock::now();
    }
    // else: maximum speed, no delay
    
    send(frame);
    return true;
}
```

### Documentation

Update the API documentation:
```cpp
/**
 * @class Mp4ReaderSource
 * @brief Reads video files and outputs frames
 * 
 * Playback Speed Control:
 * - Default: Plays at file's native FPS
 * - Custom FPS: Set playbackFPS property
 * - Maximum speed: Set playbackFPS to very high value or use setMaximumSpeed()
 * 
 * Example:
 * @code
 * Mp4ReaderSourceProps props("input.mp4");
 * props.playbackFPS = 60.0f;  // Play at 60 FPS regardless of file FPS
 * auto reader = boost::shared_ptr<Mp4ReaderSource>(new Mp4ReaderSource(props));
 * @endcode
 */
```

### Alternative: Use Throttle Module

Instead of modifying Mp4Reader, use the existing Throttle module:
```
Mp4Reader (at max speed) -> Throttle (FPS limiter) -> Rest of pipeline
```

**Pros:**
- Reuses existing Throttle module
- Separation of concerns

**Cons:**
- Two modules instead of one
- Mp4Reader still has internal timing logic

**Recommendation:** Implement both approaches:
1. Add FPS override to Mp4Reader (simple cases)
2. Keep Throttle module (complex rate control)
