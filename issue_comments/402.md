## Analysis and Suggested Implementation

### Feature Request
Support CMake COMPONENTS when finding ApraPipes package, similar to Boost and OpenCV, to allow linking only required components.

**Problem:** Currently, `find_package(ApraPipes)` links all dependencies including GTK on ARM builds, even when CUDA/GTK is not needed.

### Component Design

**Identify logical components:**
```
ApraPipes::Core       - Core pipeline functionality (always required)
ApraPipes::CUDA       - CUDA modules (H264EncoderNVCodec, etc.)
ApraPipes::GTK        - GTK-based modules (ImageViewerModule, etc.)
ApraPipes::Audio      - Audio processing modules
ApraPipes::ML         - Machine learning modules (Whisper, etc.)
ApraPipes::Network    - RTSP, HTTP modules
```

**Usage example:**
```cmake
# User CMakeLists.txt
find_package(ApraPipes REQUIRED COMPONENTS Core Network)
# This would link: Core + Network modules only (no CUDA, no GTK)
```

### Implementation Steps

**Step 1: Create component library structure**

```cmake
# In base/CMakeLists.txt

# Core library (always built)
add_library(aprapipes-core SHARED
    ${CORE_SOURCES}
)

# Optional component libraries
if(ENABLE_CUDA)
    add_library(aprapipes-cuda SHARED
        ${CUDA_SOURCES}
    )
    target_link_libraries(aprapipes-cuda PUBLIC aprapipes-core CUDA::cudart)
endif()

if(ENABLE_GTK)
    add_library(aprapipes-gtk SHARED
        ${GTK_SOURCES}
    )
    target_link_libraries(aprapipes-gtk PUBLIC aprapipes-core PkgConfig::GTK3)
endif()

# Main library (combines all enabled components)
add_library(aprapipes INTERFACE)
target_link_libraries(aprapipes INTERFACE 
    aprapipes-core
    $<TARGET_NAME_IF_EXISTS:aprapipes-cuda>
    $<TARGET_NAME_IF_EXISTS:aprapipes-gtk>
)
```

**Step 2: Create CMake config file**

Create `ApraPipesConfig.cmake.in`:
```cmake
@PACKAGE_INIT@

# Define available components
set(ApraPipes_AVAILABLE_COMPONENTS Core CUDA GTK Audio ML Network)

# Core is always required
include("${CMAKE_CURRENT_LIST_DIR}/ApraPipesCoreTargets.cmake")

# Include requested components
foreach(component ${ApraPipes_FIND_COMPONENTS})
    if(component IN_LIST ApraPipes_AVAILABLE_COMPONENTS)
        include("${CMAKE_CURRENT_LIST_DIR}/ApraPipes${component}Targets.cmake" OPTIONAL)
        
        if(NOT TARGET ApraPipes::${component})
            if(ApraPipes_FIND_REQUIRED_${component})
                message(FATAL_ERROR "ApraPipes component ${component} not available")
            endif()
        endif()
    else()
        message(FATAL_ERROR "Unknown ApraPipes component: ${component}")
    endif()
endforeach()

# Check that all required components are found
check_required_components(ApraPipes)
```

**Step 3: Export component targets**

```cmake
# Install core
install(TARGETS aprapipes-core
    EXPORT ApraPipesCoreTargets
    LIBRARY DESTINATION lib
)

# Install CUDA component if built
if(TARGET aprapipes-cuda)
    install(TARGETS aprapipes-cuda
        EXPORT ApraPipesCUDATargets
        LIBRARY DESTINATION lib
    )
    install(EXPORT ApraPipesCUDATargets
        FILE ApraPipesCUDATargets.cmake
        NAMESPACE ApraPipes::
        DESTINATION lib/cmake/ApraPipes
    )
endif()
```

### Usage Examples

**Example 1: Minimal (Core only)**
```cmake
# For headless server, no CUDA, no GTK
find_package(ApraPipes REQUIRED COMPONENTS Core Network)

target_link_libraries(myapp PRIVATE
    ApraPipes::Core
    ApraPipes::Network
)
```

**Example 2: Full features**
```cmake
find_package(ApraPipes REQUIRED COMPONENTS 
    Core CUDA GTK Audio ML Network
)

target_link_libraries(myapp PRIVATE ApraPipes::Core ApraPipes::CUDA)
```

**Example 3: Conditional (optional CUDA)**
```cmake
find_package(ApraPipes REQUIRED COMPONENTS Core)
find_package(ApraPipes COMPONENTS CUDA)  # Optional

if(TARGET ApraPipes::CUDA)
    target_link_libraries(myapp PRIVATE ApraPipes::CUDA)
    target_compile_definitions(myapp PRIVATE HAS_CUDA)
endif()
```

### Backward Compatibility

Maintain backward compatibility:

```cmake
# In ApraPipesConfig.cmake.in

# If no components specified, include all available (old behavior)
if(NOT ApraPipes_FIND_COMPONENTS)
    set(ApraPipes_FIND_COMPONENTS ${ApraPipes_AVAILABLE_COMPONENTS})
endif()
```

This ensures existing users don't break:
```cmake
# Old usage (still works)
find_package(ApraPipes REQUIRED)
# Links everything (backward compatible)
```

### Files to Create/Modify:
- `base/CMakeLists.txt` - Restructure into component libraries
- `cmake/ApraPipesConfig.cmake.in` - Component configuration
- `cmake/ApraPipesConfigVersion.cmake.in` - Version compatibility
- `README.md` - Update usage documentation

### Benefits:
- **Reduced dependencies**: Only link what you need
- **Smaller binaries**: Especially important for embedded (ApraNVR)
- **Faster builds**: Don't compile unused components
- **Clear API**: Explicit about what features are used
- **Industry standard**: Matches Boost/OpenCV pattern

### Migration Path:
1. **Phase 1**: Implement component structure (keep backward compatibility)
2. **Phase 2**: Update ApraNVR to use components
3. **Phase 3**: Document and recommend component usage
4. **Phase 4**: Consider deprecating non-component usage (major version bump)
