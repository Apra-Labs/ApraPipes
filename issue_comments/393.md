## Analysis and Suggested Implementation

### Feature Request
Add ability to store custom user-defined key-value pair metadata in MP4 files (similar to AWS resource tags).

**Use Case:** Store custom video verification/authentication metadata.

### Implementation Approach

**Step 1: Extend libmp4 to support user metadata**

```cpp
// In mp4_writer_utils.h
struct UserMetadata {
    std::string key;
    std::string value;
};

class Mp4WriterSinkProps {
public:
    // Add user metadata support
    std::map<std::string, std::string> userMetadata;
    
    void addUserMetadata(const std::string& key, const std::string& value) {
        userMetadata[key] = value;
    }
};
```

**Step 2: Write metadata to MP4 using udta (user data) atom**

```cpp
// In Mp4WriterSink.cpp
void Mp4WriterSink::writeUserMetadata() {
    // Get or create udta atom
    MP4Atom* udtaAtom = MP4FindAtom(mp4File, "moov.udta");
    if (!udtaAtom) {
        udtaAtom = MP4AddAtom(mp4File, "moov.udta");
    }
    
    // Create custom atom for user metadata
    MP4Atom* metaAtom = MP4AddAtom(mp4File, "moov.udta.meta");
    
    // Write key-value pairs
    for (const auto& [key, value] : mProps.userMetadata) {
        // Create a custom tag for each metadata entry
        std::string atomPath = "moov.udta.meta." + key;
        MP4AddStringProperty(mp4File, atomPath.c_str(), value.c_str());
    }
}
```

**Step 3: Read metadata from MP4**

```cpp
// In Mp4ReaderSource.cpp
std::map<std::string, std::string> Mp4ReaderSource::readUserMetadata() {
    std::map<std::string, std::string> metadata;
    
    // Read udta.meta atom
    MP4Atom* metaAtom = MP4FindAtom(mp4File, "moov.udta.meta");
    if (!metaAtom) {
        return metadata;  // No user metadata
    }
    
    // Iterate through properties
    uint32_t numProperties = MP4GetAtomNumProperties(metaAtom);
    for (uint32_t i = 0; i < numProperties; i++) {
        const char* name = MP4GetAtomPropertyName(metaAtom, i);
        char* value = nullptr;
        MP4GetStringProperty(mp4File, name, &value);
        
        metadata[name] = value ? value : "";
        MP4Free(value);
    }
    
    return metadata;
}
```

### Testing

```cpp
BOOST_AUTO_TEST_CASE(test_user_metadata_write_read) {
    // Write metadata
    Mp4WriterSinkProps writeProps;
    writeProps.baseFolder = "/tmp";
    writeProps.addUserMetadata("camera_id", "CAM001");
    writeProps.addUserMetadata("location", "Building A");
    writeProps.addUserMetadata("auth_hash", "sha256:test123");
    
    auto writer = boost::make_shared<Mp4WriterSink>(writeProps);
    // ... write some frames
    writer->term();
    
    // Read metadata back
    Mp4ReaderSourceProps readProps("/tmp/output.mp4");
    auto reader = boost::make_shared<Mp4ReaderSource>(readProps);
    auto metadata = reader->readUserMetadata();
    
    // Verify
    BOOST_CHECK_EQUAL(metadata["camera_id"], "CAM001");
    BOOST_CHECK_EQUAL(metadata["location"], "Building A");
    BOOST_CHECK_EQUAL(metadata["auth_hash"], "sha256:test123");
}
```

### Alternative: Use existing MP4 metadata tags

Instead of custom atoms, use standard MP4 user data:

```cpp
// Use iTunes-style metadata
MP4TagsAlloc(&tags, mp4File);
MP4TagsSetArtist(tags, "camera_id: CAM001");
MP4TagsSetComment(tags, "location: Building A");
// etc.
MP4TagsStore(tags, mp4File);
MP4TagsFree(tags);
```

**Pros:**
- Standard format
- Better tool compatibility

**Cons:**
- Limited predefined fields
- Less flexible than custom atoms

### Recommendation

Use custom udta atom for full flexibility:
- Unlimited key-value pairs
- No field restrictions
- Proper namespacing

### Files to Modify:
- `base/include/Mp4WriterSinkProps.h` - Add metadata property
- `base/src/Mp4WriterSink.cpp` - Write metadata
- `base/src/Mp4ReaderSource.cpp` - Read metadata
- `base/src/declarative/ModuleRegistry.cpp` - JSON support

### Benefits:
- Store arbitrary metadata per video
- Authentication/verification support
- Searchable/filterable video metadata
- Audit trail capability
