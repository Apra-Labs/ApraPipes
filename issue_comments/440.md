## Analysis and Suggested Implementation

### Problem
5 tests are failing on Linux NoCUDA builds:
1. `mp4v_to_jpg_frames_metadata` (6-7 sec duration)
2. `mp4v_to_h264_frames_metadata` (6-7 sec duration)
3. `test_asr` (immediate failure, 0 sec)
4. `changeprop_asr` (immediate failure, 0 sec)
5. `change_unsupported_prop_asr` (immediate failure, 0 sec)

### Analysis

**Group 1: audioToTextXform_test (immediate failures)**
These fail immediately (0 sec), suggesting:
- Missing dependencies (whisper-cpp not properly linked?)
- Initialization failures
- Environment issues (missing models, missing libs)

**Group 2: mp4readersource_tests (timeout failures)**
These take 6-7 seconds before failing, suggesting:
- File I/O issues
- Deadlock or infinite wait
- Missing codec or dependency

### Investigation Steps

#### For audioToTextXform_test failures:

**Step 1: Reproduce locally**
```bash
cd build
./aprapipesut --run_test=audioToTextXform_test/test_asr --log_level=all
./aprapipesut --run_test=audioToTextXform_test/changeprop_asr --log_level=all
./aprapipesut --run_test=audioToTextXform_test/change_unsupported_prop_asr --log_level=all
```

**Step 2: Check for missing dependencies**
```bash
# Check if whisper-cpp is properly linked
ldd build/aprapipesut | grep whisper

# Check test file for dependencies
grep -A 20 "BOOST_AUTO_TEST_CASE(test_asr)" base/test/audioToTextXform_tests.cpp
```

**Likely causes:**
1. Whisper model files not present in test environment
2. Whisper-cpp built without required features
3. Audio codec dependencies missing (OpenAL-Soft issue?)

#### For mp4readersource_tests failures:

**Step 1: Reproduce with verbose logging**

**Step 2: Check for deadlock**

The tests started failing after fixing OpenAL-Soft/fmt dependency. Check:

**Issue 1: Linker order changed**
```cmake

    PRIVATE

```

**Issue 2: Symbol conflicts**

**Issue 3: Missing runtime dependencies**

### Fixes

**For audioToTextXform_test:**

**Option 1: Skip tests if whisper not available**
```cpp
BOOST_AUTO_TEST_CASE(test_asr) {
    #ifdef ENABLE_WHISPER
        // ... test code
    #else
        BOOST_TEST_MESSAGE("Whisper not available, skipping test");
    #endif
}
```

**Option 2: Fix whisper initialization**
```cpp
// In AudioToTextXForm.cpp
bool AudioToTextXForm::init() {
    try {
        // Add proper error handling for model loading
        if (!loadWhisperModel()) {
            LOG_ERROR << "Failed to load whisper model";
            return false;
        }
    } catch (const std::exception& e) {
        LOG_ERROR << "Whisper initialization failed: " << e.what();
        return false;
    }
}
```
