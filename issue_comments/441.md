## Analysis and Suggested Implementation

### Problem
No CUDA build shouldn't build whisper with CUDA support. Currently, whisper is being built with CUDA even in NoCUDA builds, similar to how we handle OpenCV.

### Root Cause Analysis

The issue is in the vcpkg dependency configuration. When `ENABLE_CUDA=OFF`, whisper dependencies should not include CUDA-related features.

**Files to check:**
- `base/vcpkg.json` - Main vcpkg manifest
- `base/vcpkg-configuration.json` - vcpkg configuration
- CMake configuration for whisper

### Solution: Conditional Features

**Option 1: Use vcpkg features (Recommended)**

Update `base/vcpkg.json`:
```json
{
  "name": "aprapipes",
  "dependencies": [
    {
      "name": "whisper-cpp",
      "features": ["cuda"],
      "platform": "!nocuda"
    },
    {
      "name": "whisper-cpp",
      "platform": "nocuda"
    }
  ]
}
```

**Option 2: CMake-level control**

In the main CMakeLists.txt:
```cmake
if(ENABLE_CUDA)
    find_package(whisper-cpp CONFIG REQUIRED COMPONENTS cuda)
else()
    find_package(whisper-cpp CONFIG REQUIRED)
    # Ensure no CUDA symbols are linked
    target_compile_definitions(aprapipes PRIVATE WHISPER_NO_CUDA)
endif()
```

### Implementation Steps

**Step 1: Update vcpkg.json**
- Add conditional features for whisper-cpp based on CUDA availability
- Similar to how opencv is handled

**Step 2: Update CMakeLists.txt**
```cmake
# In base/CMakeLists.txt
if(ENABLE_CUDA)
    set(WHISPER_FEATURES "cuda")
else()
    set(WHISPER_FEATURES "")
endif()
```

**Step 3: Verify OpenCV pattern**
Examine how OpenCV handles this:
```bash
grep -r "opencv" base/vcpkg.json
grep -r "ENABLE_CUDA" base/CMakeLists.txt | grep -i opencv
```
