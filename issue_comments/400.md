## Analysis and Suggested Implementation

### Problem
The issue occurred because `nextPtrOffset` was being initialized in the `RawImagePlanarMetadata` class when setting the data size for the first time. The condition checking prevented the data size from being updated correctly on the second attempt.

### Root Cause

The initialization logic for `nextPtrOffset` is conflicting with the update logic, preventing subsequent updates.

### Solution

**Fix the initialization and update logic:**

```cpp
// In RawImagePlanarMetadata.cpp or .h
class RawImagePlanarMetadata {
private:
    size_t nextPtrOffset;
    bool initialized;
    
public:
    RawImagePlanarMetadata() : nextPtrOffset(0), initialized(false) {}
    
    void setDataSize(size_t width, size_t height, ImageType type) {
        // Calculate offsets based on image type
        size_t ySize = width * height;
        size_t uvSize = (width * height) / 4;  // For YUV420
        
        // Don't check if value is same - allow updates
        // Remove the problematic condition that was blocking updates
        
        // Update offsets
        nextPtrOffset = ySize;  // U plane starts after Y
        
        // Set initialized flag
        initialized = true;
        
        // Store dimensions
        this->width = width;
        this->height = height;
        this->type = type;
    }
};
```

### Alternative Fix

If the condition was checking for unchanged values to avoid unnecessary work:

```cpp
void setDataSize(size_t width, size_t height, ImageType type) {
    // Check if actually changed, not if "same as declared"
    if (initialized && 
        this->width == width && 
        this->height == height && 
        this->type == type) {
        // Nothing changed, return early
        return;
    }
    
    // Proceed with update
    size_t ySize = width * height;
    nextPtrOffset = ySize;
    
    // Update all fields
    this->width = width;
    this->height = height;
    this->type = type;
    initialized = true;
}
```
